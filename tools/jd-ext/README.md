# 京东订单收割 → 自动填商品名：使用教程

> 这个扩展是干嘛的：你在京东买的每笔订单，商品名（比如「tomtoc轻便斜挎包」）
> 会被它记下来。导入两步记账后，补备注时**自动帮你把商品名填好**，不用手打。
>
> 安全说明：它只"旁听"你京东订单页自己加载的数据，**不碰你的账号密码/Cookie，
> 不发送任何请求，不上传任何数据**。所有记录只存在你自己的浏览器里。

---

## 第一步：安装扩展（只需做一次，约 1 分钟）

1. 打开 Edge 浏览器，在地址栏输入 `edge://extensions` 回车
2. 把页面**左下角**的「开发人员模式」开关打开
3. 点页面上方出现的「**加载解压缩的扩展**」按钮
4. 在弹出的文件夹选择框里，选中项目里的 **`tools/jd-ext`** 这个文件夹，点"选择文件夹"
5. （建议）点浏览器右上角的拼图🧩图标，给这个扩展点一下「固定」—— 以后好找

装好后浏览器顶部会出现「两步记账 · 京东收割」的图标。

## 第二步：收割订单（每次想更新商品名时做一次，约 2 分钟）

1. 点扩展图标，弹出小窗
2. 点紫色按钮「**开始收割**」，状态栏变成"收割中"
3. 在同一个浏览器里打开京东订单页：`order.jd.com`
   - 如果提示登录，就用**京东 App 扫码**登录（这是你自己的浏览器，登录一次以后基本不用再登）
4. 在订单页里，**把订单列表一直往下翻，翻到底**（滚轮往下滚，直到出现"没有更多了"）
   - 每翻一页，那一页的订单就被自动记下了
   - 可以随时点扩展图标看进度：「已收割 N 单」的 N 会一直涨
5. 点扩展图标 → 「**停止**」→ 「**导出订单快照**」
   - 浏览器会下载一个 `jd-snapshot-xxxx.json` 文件
   - 导出前确认状态栏显示的「已收割 N 单」不是 0；如果是 0，说明没翻到订单列表

> 💡 提示：京东订单页只保留**最近几个月**的订单，更早的收不到，这是京东的限制。
> 已删除的订单也收不到（回收站里的不算）。

## 第三步：导入两步记账（约 10 秒）

1. 打开两步记账网页，点顶部「**设置**」页签
2. 找到「**京东订单快照**」卡片，点「导入快照」，选刚下载的那个 json 文件
3. 显示导入了多少单就成功了

## 第四步：享受自动备注

进「补备注」页，处理京东的交易时：

- 备注框会**自动预填**从快照匹配到的商品名（按订单号精确匹配，也支持一个微信支付对应多个京东子单的情况）
- 你可以随便改再保存；**已经写过的备注不会被自动覆盖**（但会显示一个紫色「填入」按钮，点了可以一键替换）
- 没匹配到的照常手写，互不影响

## 更新扩展代码后必须做的一步

如果以后我改了扩展的代码，你需要：

1. 打开 `edge://extensions`
2. 找到「两步记账 · 京东收割」，点它卡片上的「**重新加载**」🔄 图标
3. 不重新加载的话，扩展还是跑的旧代码，会出各种奇怪问题
   （新版扩展检测到这种情况会自己在状态栏红字提醒你）

## 常见问题

| 问题 | 解决 |
| --- | --- |
| 导出的 json 是空的 / 状态栏红字 | 看红字提示。最常见原因：代码更新后没「重新加载」扩展 |
| 已收割 N 单 不涨 | 确认在 `order.jd.com` 页面里往下翻；确认点过「开始收割」 |
| 收割不到某笔订单 | 那笔订单被删除了，或超出了京东保留的订单时间范围 —— 手写备注即可 |
| 顶部「正在调试此浏览器」提示条 | 正常现象，是扩展在旁听订单页数据，点 X 关掉提示条不影响使用 |
| 想清掉浏览器里的记录 | 点扩展 → 「清空本机快照」（不影响已导入两步记账的数据） |
| 换浏览器 / 重装系统 | 扩展是本地安装的，重装后按第一步再来一遍；快照重新收割一次即可 |

## 文件说明（给想研究代码的人）

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | 扩展清单（MV3）。权限只有 debugger/tabs/storage，**没有 cookies** |
| `background.js` | 核心逻辑：attach 订单页 → 旁听订单列表接口响应 → 提取快照 → 本机存储 |
| `popup.html` / `popup.js` | 小窗界面：开始/停止/导出/清空 |
